Frage 251: Wenn man in Deutschland ein Kind schlägt, ...

  1. geht das niemanden etwas an.
  2. geht das nur die Familie etwas an.
  3. kann man dafür nicht bestraft werden.
  4. kann man dafür bestraft werden.

Warum? Kinder haben ein Recht auf gewaltfreie Erziehung (Paragraf 1631 Bürgerliches Gesetzbuch). Schlagen ist verboten.

Frage 252: In Deutschland ...

  1. darf man zur gleichen Zeit nur mit einer Partnerin/einem Partner verheiratet sein.
  2. kann man mehrere Ehepartnerinnen/Ehepartner gleichzeitig haben.
  3. darf man nicht wieder heiraten, wenn man einmal verheiratet war.
  4. darf eine Frau nicht wieder heiraten, wenn ihr Mann gestorben ist.

Warum? In Deutschland gilt die Einehe: Man darf nur mit einer Person gleichzeitig verheiratet sein.

Frage 253: Wo müssen Sie sich anmelden, wenn Sie in Deutschland umziehen?

  1. beim Einwohnermeldeamt
  2. beim Standesamt
  3. beim Ordnungsamt
  4. beim Gewerbeamt

Warum? Nach einem Umzug muss man sich beim Einwohnermeldeamt (Bürgeramt) anmelden. Das ist die Meldepflicht.

Frage 254: In Deutschland dürfen Ehepaare sich scheiden lassen. Meistens müssen sie dazu das "Trennungsjahr" einhalten. Was bedeutet das?

  1. Der Scheidungsprozess dauert ein Jahr.
  2. Die Ehegatten sind ein Jahr verheiratet, dann ist die Scheidung möglich.
  3. Das Besuchsrecht für die Kinder gilt ein Jahr.
  4. Die Ehegatten führen mindestens ein Jahr getrennt ihr eigenes Leben. Danach ist die Scheidung möglich.

Warum? Trennungsjahr bedeutet: Die Eheleute leben mindestens ein Jahr getrennt. Erst danach ist die Scheidung normalerweise möglich.

Frage 255: Bei Erziehungsproblemen können Eltern in Deutschland Hilfe erhalten vom ...

  1. Ordnungsamt.
  2. Schulamt.
  3. Jugendamt.
  4. Gesundheitsamt.

Warum? Das Jugendamt berät und unterstützt Eltern bei Problemen mit der Erziehung.

Frage 256: Ein Ehepaar möchte in Deutschland ein Restaurant eröffnen. Was braucht es dazu unbedingt?

  1. eine Erlaubnis der Polizei
  2. eine Genehmigung einer Partei
  3. eine Genehmigung des Einwohnermeldeamts
  4. eine Gaststättenerlaubnis von der zuständigen Behörde

Warum? Für ein Restaurant braucht man eine Erlaubnis von der zuständigen Behörde. Sie heißt Gaststättenerlaubnis.

Frage 257: Eine erwachsene Frau möchte in Deutschland das Abitur nachholen. Das kann sie an ...

  1. einer Hochschule.
  2. einem Abendgymnasium.
  3. einer Hauptschule.
  4. einer Privatuniversität.

Warum? Am Abendgymnasium können Erwachsene das Abitur nachholen. Das nennt man zweiten Bildungsweg.

Frage 258: Was darf das Jugendamt in Deutschland?

  1. Es entscheidet, welche Schule das Kind besucht.
  2. Es kann ein Kind, das geschlagen wird oder hungern muss, aus der Familie nehmen.
  3. Es bezahlt das Kindergeld an die Eltern.
  4. Es kontrolliert, ob das Kind einen Kindergarten besucht.

Warum? Das Jugendamt schützt Kinder. Bei Gefahr für das Kind darf es das Kind aus der Familie nehmen.

Frage 259: Das Berufsinformationszentrum BIZ bei der Bundesagentur für Arbeit in Deutschland hilft bei der ...

  1. Rentenberechnung.
  2. Lehrstellensuche.
  3. Steuererklärung.
  4. Krankenversicherung.

Warum? Das Berufsinformationszentrum (BIZ) informiert über Berufe und hilft bei der Suche nach einer Lehrstelle.

Frage 260: In Deutschland hat ein Kind in der Schule ...

  1. Recht auf unbegrenzte Freizeit.
  2. Wahlfreiheit für alle Fächer.
  3. Anspruch auf Schulgeld.
  4. Anwesenheitspflicht.

Warum? In Deutschland gilt die Schulpflicht. Kinder müssen deshalb am Unterricht teilnehmen.
